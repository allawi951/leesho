# نماذج تطبيقات — علي وليشو

نماذج تجريبية ببيانات وهمية تُظهر وش نقدر نسوي لشغلك. كل نموذج صفحة مستقلة (HTML/CSS/JS بدون بناء) وحالته محفوظة في متصفح الزائر مع زر «إعادة ضبط النموذج».

- [لوحة حسابات المحل](dashboard/) — دفتر يومي للدخل والمصروفات حسب الأصناف لمقهى: تقويم شهري ملوّن، فلاتر، مؤشرات ورسوم بيانية، وإضافة/تعديل/حذف القيود.
- [منيو رقمي بسلة طلبات](menu/) — منيو QR لمطعم: أقسام وأصناف وخيارات وملاحظات، طاولة أو استلام، ومعاينة رسالة الطلب كما توصل لواتساب المطعم (بدون إرسال فعلي).
- [نظام حجز مواعيد](booking/) — حجز لمركز عناية بالسيارات: خدمة، يوم، وقت متاح، بيانات العميل، معاينة رسالة الحجز، ولوحة صاحب المحل لحجوزات اليوم.
- [بطاقة ولاء رقمية](loyalty/) — بطاقة أختام لمقهى (٦ والسابع مجاني): أختام متحركة، مكافأة، سجل زيارات، ووضع كاشير برمز تجريبي.
