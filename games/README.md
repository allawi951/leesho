# ألعاب نموذجية للمطاعم (علي وليشو)

كلها HTML/CSS/JS عادي بدون بناء ولا سيرفر، وتشتغل بدون إنترنت بعد التحميل. افتح `index.html` في كل مجلد.

- `order-rush/` — **ركّب الطلب**: اختر قائمة (برجر، شاورما، بيتزا، قهوة)، اضغط المكوّنات بنفس ترتيب ورقة الزبون ثم «قدّم» قبل ما ينفد صبره؛ الغلط يعيدك من جديد، والجولة 75 ثانية وأعلى نتيجة تنحفظ.
- `table-talk/` — **سوالف الطاولة**: جوال واحد للطاولة؛ أضف الأسماء (اختياري) واختر أنواع البطاقات (ضحك، ذكريات، لو خيروك، تعرف علينا، تحدي خفيف)، اضغط أو اسحب البطاقة لتنقلب، ثم «تمام — مرّر الجوال» أو «تخطي»، بدون تكرار حتى تنتهي البطاقات.
- `forbidden-word/` — **الكلمة الممنوعة**: فريقين على جوال واحد؛ الواصف يشرح الكلمة بدون الكلمات الممنوعة والوقت يمشي، وأزرار صح / ممنوع / تخطي (٣ تخطيات للدور)، وتنتهي بشاشة الفائز.

لا أصول خارجية: الرسم بالإيموجي وCSS، والصوت يتولّد بـ Web Audio. الخط Cairo من Google Fonts اختياري (يرجع لخط النظام بدون إنترنت).
